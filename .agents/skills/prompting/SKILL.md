# Prompting

Keep session-wide rules and skill triggers in `AGENTS.md`. Put each repeatable workflow in the matching `.agents/skills/<name>/SKILL.md`, with a short description that identifies when to use it.

State checkable rules and explain their reasons when they affect unfamiliar cases. Put each rule in one place, verify the commands and links, and keep supporting references only when a specific workflow needs them.
